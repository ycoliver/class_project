\section{Introduction}

This report presents the implementation and results of search algorithms applied to the 8-puzzle problem. The student ID is \textbf{225040015} (odd number), so \textbf{Depth-First Search (DFS)} is the required primary algorithm, together with \textbf{A* Search} using the Manhattan distance heuristic. The digit \texttt{0} represents the blank tile.

% ─────────────────────────────────────────────────────────────────
\section{Problem Representation}

The 8-puzzle board is encoded as a 9-character string in row-major order, where \texttt{0} is the blank tile:

\begin{lstlisting}[style=mono]
String index:  0 1 2 3 4 5 6 7 8
Grid layout:   [0][1][2]
               [3][4][5]
               [6][7][8]

Example: '283164705'  =>   2 8 3
                           1 6 4
                           7 0 5   (0 = blank tile)
\end{lstlisting}

\textbf{Parity} is determined by counting \emph{inversions} in the tile sequence (ignoring \texttt{0}). An inversion is a pair $(i, j)$ where $i < j$ but \texttt{tile[i] > tile[j]}. Two states are mutually reachable if and only if their inversion counts share the same parity (both odd or both even).

% ─────────────────────────────────────────────────────────────────
\section{Algorithms}

\subsection{Depth-First Search (DFS)}
Uses an explicit stack with a \textbf{global visited set} to prevent revisiting states, and a \textbf{depth limit of 50} to avoid infinite traversal. DFS does \emph{not} guarantee the shortest (optimal) path.

\subsection{A* Search}
Uses a min-heap ordered by $f(n) = g(n) + h(n)$, where $g(n)$ is the path cost from the start and $h(n)$ is the \textbf{Manhattan distance heuristic}:
\[
  h(n) = \sum_{\text{tile} \neq 0} \bigl(|\text{row}_{\text{current}} - \text{row}_{\text{goal}}| + |\text{col}_{\text{current}} - \text{col}_{\text{goal}}|\bigr)
\]
This heuristic is \emph{admissible} and \emph{consistent}, guaranteeing the optimal solution.

\section{Task C1 --- Parity Test}

The first two tiles (\texttt{2} and \texttt{8}) are swapped in the start state:

\begin{lstlisting}[style=mono]
Original start : 283164705  (inversions: 11 -- ODD)
Swapped  start : 823164705  (inversions: 12 -- EVEN)
Goal state     : 123804765  (inversions:  7 -- ODD)

same_parity(original, goal) = True   =>  Solvable
same_parity(swapped,  goal) = False  =>  Unsolvable
\end{lstlisting}

Running DFS on the swapped start exhausts all reachable states and confirms \textbf{no solution exists}. This verifies the parity invariant: swapping any two tiles changes the inversion count parity, making the goal state unreachable.

\section{Analysis and Conclusion}

\textbf{Efficiency.}
A* dramatically outperforms DFS in terms of nodes expanded. For the fixed puzzle, DFS expanded \textbf{101,085} nodes while A* expanded only \textbf{6}. For the random puzzle: \textbf{107,457} versus \textbf{612}. The Manhattan distance heuristic effectively prunes the search space.

\textbf{Solution Quality.}
A* guarantees the optimal (shortest) path. DFS found 5 moves for the fixed puzzle --- coincidentally matching the optimal --- but required \textbf{41 moves} for the random puzzle, nearly double A*'s optimal \textbf{21 moves}.

\textbf{Parity.}
The parity test confirms a fundamental invariant of the 8-puzzle: swapping any two tiles changes the inversion count by an odd number, flipping parity. DFS correctly exhausted all reachable states with no solution found when parity differs.

\textbf{Conclusion.}
A* with the Manhattan distance heuristic is highly efficient and guarantees optimal solutions for the 8-puzzle. DFS, while complete with visited-set tracking and depth limiting, is neither optimal nor computationally efficient for more complex instances.
